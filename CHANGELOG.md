# Changelog

## 0.2.0 - 2026-10-07

### Fifth pass: "Seen by you" loot

- New `SeenLoot.lua`: after a boss kill (`ENCOUNTER_END`, same encounter ID as `LootData.lua`), items looted from that boss's corpse are saved
  per character in `DungeonLensDB.seenLoot[encounterID][itemID]`. Only slots whose source GUID is a boss unit count; trash loot is ignored.
- The boss panel lists them under **SEEN BY YOU** (marked not verified), never repeating a verified item. Bosses with no data say
  "No verified loot yet" (was "Loot data unavailable").
- `/dlmap lootexport` prints recorded items per encounter so they can be promoted into verified data.
- New `DungeonLevels.lua`: recommended level range per dungeon (source: foreverdb.net), shown in the dungeon list as `Lv 13-18`.
- The Hall of Thanes map now uses its WMO minimaps instead of terrain tiles (which showed a black blank cell, a grey backdrop and the dungeon
  small and off-centre). Same dungeon-wide view as the other WMO maps; ground-tile rendering stays covered by a synthetic smoke fixture.
- Ruins of Lordaeron now uses its terrain-tile map, cropped to the walled ruined city (the dungeon itself). It previously drew the Undercity
  interior WMO, an underground piece placed in the same map that is not the dungeon. Ground maps can carry an optional pixel `crop`
  (manifest -> `MapData.lua`), applied as clipped tiles with matching UVs.
- **Minimap button** (`MinimapButton.lua`, no libraries): left-click opens/closes the dungeon browser, right-click opens the map of the
  dungeon you are in, drag moves it around the minimap rim (round or square minimaps); position and visibility are saved, and
  `/dlmap minimap on|off|reset` controls it. It only polls the cursor while being dragged.
- **Entrance card:** the top-left of every dungeon map shows where the entrance is (zone and coordinates, e.g. "Orgrimmar 53.0, 48.9") and a
  **Show on world map** button: it opens the zone's world map and places the standard map pin (`C_Map` user waypoint, also on the minimap);
  if an API is unavailable the location is printed to chat instead. Positions come from Forever's own `Map` corpse-run coordinates
  (`DungeonEntrances.lua`, generated by `scripts/Build-Entrances.py`, with a check that the point lies inside the named zone). Ruins of
  Lordaeron uses the new Forever `AreaTrigger` at the walled city's keep (Tirisfal Glades); The Hall of Thanes is zone-only (Ironforge, no
  published coordinates) and opens the map without a pin.
- **Boss table:** opening a dungeon shows a BOSSES table at the top right with every boss (placed on the map or not) and its loot count. Clicking
  a row opens that boss's loot panel, switching to the boss's floor first when it is placed on another one; the panel's button is now "< Bosses".
  This makes loot reachable for bosses that have no map pin (Hall of Thanes, Ruins of Lordaeron). A listed boss whose pin is merely hidden
  (approximate pins off) no longer closes its panel.
- Verified loot grew from 53 to 62 bosses (127 to 170 items): Forever-new items have no name in the client tables, so their IDs now come
  from foreverdb.net item links (`scripts/generated/loot/foreverdb-ids.json`) and ship only when the ID exists in Forever's Item table and its
  equip slot fits the listing. Bosses are now registered for terrain-tile maps too (Ruins of Lordaeron), so their loot is reachable.
- **Learned boss positions:** a boss with no verified pin gets a blue-tinted "seen" pin where you looted it (the position at its own corpse,
  averaged over your last 5 kills, stored raw in `DungeonLensDB.seenBossPos`). Works on WMO maps through the registered frame and on terrain-tile
  maps through the ADT tile grid (`PositionProbe.lua`); verified pins always win. `/dlmap lootexport` also prints the raw positions.
- Revelosh, Ironaya and Mordresh now have verified loot (Classic ID chosen over the 2173xx reissue when the listing says not Forever-new).

### Fourth pass: boss loot

- Boss markers are clickable and open a right-side loot panel (icon, quality-coloured name, slot/type); hovering an item shows the real
  Blizzard item tooltip. Items are keyed by numeric itemID; uncached items are requested and the row updates on `GET_ITEM_INFO_RECEIVED`.
- `LootData.lua` (generated): 119 verified item IDs on 51 bosses from a Forever-specific listing, joined by the same encounter IDs as
  `BossData.lua`. No drop rates are shipped. Provenance and every unresolved item: `scripts/LOOT-PROVENANCE.md`.
- The panel closes on Close, on clicking empty map, on Back, on dungeon change, and when a floor change removes the boss.
- `previews/index.html` lists each boss's loot (and unverified items) in an expandable row.

### Third pass: click-through UI

- `/dlmap` now opens a **dungeon browser** inside the same window: all 14 dungeons with boss/floor counts, Excavation Site shown as
  Unavailable, an optional CURRENT DUNGEON section, scrolling, hover and selected-row states.
- Clicking a dungeon shows its map in place; **< Dungeons** returns to the list without recreating the window; floor/wing navigation is
  `<  Floor 2 of 4  >` in the header (named for Scarlet Monastery's wings) and updates boss pins.
- Verified boss pins show automatically (hover = boss name); approximate pins need `/dlmap approximate on`.
- Normal UI shows no development text (candidate/WMO/IDs live in `/dlmap debug`). `show/list/floor/live` remain as hidden conveniences.

### Second pass: browse, bosses, floors, offline QA

- `/dlmap show <name|id>`, `/dlmap list`, `/dlmap floor`, `/dlmap live` and a **Dungeons** dropdown open any registered dungeon from anywhere,
  clearly titled as a preview; validation and rendering safety are unchanged.
- Generated maps for 12 dungeons (+ hand-verified RFC): Stockade, Wailing Caverns, BFD, Uldaman, Gnomeregan, Razorfen Kraul/Downs, Shadowfang Keep,
  Ruins of Lordaeron, Hall of Thanes (ground), Deadmines (main WMO) and Scarlet Monastery (four wing pages). Excavation Site stays unresolved.
- Real floors from Blizzard's own UiMapAssignment (Gnomeregan 4, Shadowfang Keep 7, BFD 3, Uldaman 2) transferred by WMOAreaTable group ID.
- Boss markers (raid-target skull) generated with provenance for 11 dungeons; status gating (approximate = development only), floor-aware,
  signature-bound. Boss tables: `scripts/BOSS-PROVENANCE.md`.
- Proven world-to-canvas transform (`scripts/FRAME-FIT.md`) and a gated, development-only player marker (`/dlmap player on`).
- Offline QA: `scripts/Build-Previews.py` -> `previews/index.html` rendered from the addon's own Lua layout; `Verify-Layout.py` proves the
  Python mirror equals the Lua layout for all 28 layouts.

- Build 70245 discovery pipeline (`scripts/Discover-Dungeons.py`, `wago_client.py`): Map/UiMap DB2 join, WDT MAID
  minimap tables, ADT-placed WMOs, root-WMO MOGI bounds, BLP headers, rho fit, blank-tile detection, A-E classification.
- `scripts/Generate-Registry.py` generates `MapData.lua` (candidates, keyed by InstanceID); RFC 389 stays the
  hand-verified entry and is cross-checked against rediscovered data (`--check`).
- Ground-minimap renderer path (`blizzard-ground-minimap`); generalized WMO raster rule (760/760 groups, 14 dungeons).
- Fixed draw-sublevel overflow for WMOs with more than 16 groups (RFC unchanged).
- Candidate maps for Stormwind Stockade (34), Gnomeregan (90), Hall of Thanes (3065); `/dlmap candidates on|off`.
- Generic overlay layer (`Overlay.lua`, `MarkerData.lua`), authoring mode (`/dlmap author`) and `/dlmap probe`.
  No player marker, no M-key integration, no release packaging.

## 0.1.0 — unreleased

- Initial native current-instance map viewer targeting Forever beta 1.60.1,
  Interface 16001 and Lua 5.1.
- Added `/dlmap`, `/dlmap debug` and `/dlmap close`.
- Added guarded build/instance/map/artwork diagnostics, parent/child/group
  candidates and one-shot player-position investigation.
- Added event-driven dungeon/raid detection with a single state table and
  conservative current-map/ancestor selection.
- Added a movable, resizable window with ESC/close controls and SavedVariables
  for position, size and visibility.
- Added native tiled-map rendering with uniform aspect fitting, partial edge
  cropping, complete-layer validation and graceful missing-art fallback.
- Added verified development junction installation, focused Lua 5.1 smoke
  checks, a manual acceptance checklist and runtime-only ZIP packaging.
- Player marker, manual floor controls and M-key integration remain disabled
  pending actual Forever runtime evidence. In-game acceptance is pending;
  no public release archive or upload has been made.
